# Cellar & Paper 酒窖與紙張
Where wine is kept, and written. 收藏酒，也收藏字。

## 檔案
- `index.html` — 網站（所有內容資料都在這個檔案裡）
- `design-system.html` — 設計系統說明頁
- `assets/tokens.css` — 顏色、字型、間距
- `assets/site.css` — 內容元件樣式（筆記、產區、考題）
- `assets/app.css` — 網站版面與各分頁樣式
- `assets/app.js` — 分頁切換、酒架、翻牌、酒窖簿等互動

## 上傳 GitHub Pages
把資料夾裡全部檔案（含 assets 資料夾）上傳到 repository 根目錄，Settings → Pages 選 main / root。
個人紀錄（已讀、收藏、翻牌、酒窖簿）存在使用者自己的瀏覽器，可在 My Cellar 備份匯出。
